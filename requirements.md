# Sprint 0 Requirements

## Functional requirements
- Users can browse products.
- Users can search products.
- Users can filter products.
- Users can view product details.
- Users can type a normal-language request.
- The advisor can match products from title, category, description, and price.
- The advisor can show reasons for the match.
- The app can compare two or more close options.

## Non-functional requirements
- The first release targets Android.
- The interface should be simple for new online shoppers.
- Recommendations must be explainable.
- The advisor must remain rule-based in this project.

## Out of scope for the first version
- Full marketplace operations
- Trained machine-learning models
- LLM-based chat
